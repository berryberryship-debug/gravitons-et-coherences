# Gravitons et Cohérence

Ce dépôt contient mes recherches sur la géométrie pré-spatiale, le flot de Toda et la positivité des matrices de Markov appliquées à la gravité quantique.

## Résultats récents
- Mise en évidence d'une divergence logarithmique du temps critique \(t_c\) pour la chaîne d'Ehrenfest paresseuse.
- Ajustement numérique : \(R^2 = 0.999771\), pente \(a = 16.1235\) (théorique : \(n/2 = 15.5\)).
